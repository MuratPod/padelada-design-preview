Padelada Watch · sorteo y saque

Prototipo de diseño, no es el motor del partido. Toca el marcador para sumar un punto.

Demo

  1. «Empezar»: eliges quién saca; el reloj sigue el saque y las estadísticas.
  2. «Sorteo»: el reloj elige al azar; puedes cambiarlo.
  3. «Solo marcador»: solo puntos. Desde el seguimiento (···) se pide confirmación y no se vuelve hasta un set nuevo.
