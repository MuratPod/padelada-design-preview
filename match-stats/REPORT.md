# match-stats — отчёт (marker: match-stats-html-20261107)

Кликабельный браузерный прототип «Статистика матча» (демо, вымышленные данные). Вход: `index.html`, раздел `#/list` → матч 7 ноября.

## Что сделано
- Источник: ZIP дизайнера (SHA256 `72f90cc4…c1fb798` сверен), spec/manifest/data прочитаны полностью.
- Гибрид: **Обзор, Игроки, Компания, Карточка матча** — одобренные PNG (SE/390/Pro Max по ширине окна) с кнопками-хотспотами из manifest (масштаб в %). **Игрок (4 шт.), Ход матча, лист «Как считаем», список матчей** — настоящий HTML из `data/match_demo.json`.
- Игроки: у каждого свои цифры (Ана, Лео, Мурат, Карлос), MVP-бейдж только у Мурата. Часы (нагрузка % к личной норме, пульс, зоны, график) — только Мурат и Лео; у Ана и Карлоса компактная карточка «Без данных часов», не нули. Формулировки нейтральные, без оценки старания и медицинских выводов.
- Ход матча: фильтры Все/Сет 1/Сет 2/Сет 3/Брейки реально меняют строки, графики и заголовки; поворотный момент (set 3, game 9) подсвечен, переход с Обзора ведёт к нему.
- «?» открывает лист определений с нужным разделом, закрытие: ✕, Esc, фон. Share: превью, «Отправить»/«Сохранить» — только демо-тост, без сети.
- Назад из Обзора — работающий список матчей (текущий + 13 вымышленных прежних).
- Плашка «Демо • вымышленные данные» на каждом экране. Без внешних запросов и шрифтов (системный шрифт вместо Montserrat/Golos, не вшиты).
